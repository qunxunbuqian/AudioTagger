# 音频标签工具（AudioTagger）

给安卓手机里的 MP3、M4A、WAV 等音频批量写入歌手、专辑、歌名和内嵌封面。

## 简介

AudioTagger 是一个面向本地音乐库的安卓工具，不需要电脑中转。它可以递归扫描音乐文件夹，按文件名中的 `歌手名 - 歌曲名` 自动分组，批量写入歌手、专辑、歌名和内嵌封面，也支持从 B 站公开视频直接新增音频。

适合这些场景：

- 从不同来源下载的歌曲，歌手、专辑和封面信息不完整。
- 一位歌手有很多首歌，需要按文件夹批量处理。
- B 站下载的音频文件命名、标签和封面不统一。
- 想先处理一部分歌曲，再回来继续处理剩余的歌曲。

## 主要功能

- 批量写入歌手、专辑、歌名和内嵌封面。
- 自动识别 `歌手名 - 歌曲名` 文件名，并按歌手分组。
- 手动填写歌手，支持记住某个文件夹的歌手。
- 按已写入 / 未写入、专辑筛选歌曲，只处理勾选部分。
- 按歌手批量回写文件名，保持 `歌手名 - 歌曲名` 格式。
- 支持 MP3、M4A、WAV、FLAC、OGG、OPUS、AIFF 等格式。
- 从 B 站链接、BV 号或 av 号新增音频，自动写入视频封面。
- 对 B 站分片 M4S 自动重封装，避免直接改后缀导致播放器卡退。

## 安装

APK 下载：[GitHub Releases](https://github.com/qunxunbuqian/AudioTagger/releases/latest)

1. 把 APK 传到手机并安装。系统提示“未知来源应用”时，允许当前文件管理器安装。
2. 首次打开会要求“所有文件访问”权限，点按钮去系统设置里打开。
3. 回到 App，选择音乐根文件夹。

> 这是侧载应用，不在应用商店上架。Android 17 如果限制较严，请在系统设置的“特殊应用权限 → 所有文件访问”里手动允许。

## v1.9 新增

- **修复 B 站音频下载 403**：音频下载会带上 B 站 `buvid3/buvid4` Cookie 和视频页 Referer；DASH 音轨失败时会自动尝试 `html5` 备用接口，下载合并 MP4 后只抽取音频轨，再生成 `.m4a`。
- **视频封面自动写入**：B 站音频导入本来就会自动下载视频封面、裁成正方形 JPEG 并写入新音频；不需要再单独设置封面。
- 失败提示会带上出错的 CDN 主机名，方便判断是接口限制还是某个 CDN 节点不可用。
- 如果一个视频同时没有 DASH 音频和可用的合并音轨，才会报失败；会员、付费、地区限制视频仍可能无法下载。

## v1.8 新增

- **专辑识别修复**：重新扫描时会读取音频文件里已经存在的专辑标签（MP3 的 `TALB`、M4A 的专辑字段，以及 WAV 的 `RIFF LIST/INFO`），并显示在歌手卡片、单曲编辑和“按专辑筛选”里。只有文件没有内嵌专辑、也没有手动设置时，才使用默认专辑“投稿”。
- **新增 B 站音频下载**：主界面右上角的下载图标可以打开“新增 B 站音频”。粘贴视频链接、BV 号或 av 号，填写歌手名；歌曲名留空时使用视频标题，专辑默认“投稿”。App 会下载公开视频中码率最高的音频轨，重封装成 `.m4a`，写入歌手、歌名、专辑和视频封面。
- **保存位置与命名**：如果已经有同名歌手的文件夹，就保存到那个文件夹；否则保存到当前音乐根目录。文件名格式为 `歌手名 - 歌曲名.m4a`，同名文件自动加 `(2)`。
- **自动刷新**：下载并写入完成后会自动重新扫描，新增歌曲会直接出现在歌手列表里。
- B 站音频一次处理一个公开视频；会员、付费、地区限制或已删除的视频可能失败，App 不会绕过这些限制。

## v1.7 新增

- **默认专辑改为“投稿”**：没有单独设置过的歌手组默认写入“投稿”，仍可在歌手卡片或单曲编辑里修改。
- **只重命名勾选的歌曲**：歌手卡片点“按歌手改名”时，只处理当前勾选的歌曲，不再强制处理整组。
- **WAV 标签写入**：新增对 `.wav` 的歌手、专辑、歌名和内嵌封面写入；WAV 使用 ID3 标签块，原音频数据保持不变。
- **全局全选 / 全不选**：批量选择卡片可以直接选中或取消所有歌曲。
- **按专辑筛选和批量设置**：按专辑筛出歌曲后，可以全选当前结果、逐首勾选，再批量写入新的专辑名。

## v1.5 新增

- **按歌手批量改名**：歌手卡片里点“按歌手改名”，把这一组的文件统一改成 `歌手名 - 歌名`，扩展名保持不变。目标文件已存在时会自动加 `(2)`，不会覆盖。
- **已写入 / 未写入筛选**：查看歌曲时可以按写入状态筛选，再点“仅选当前”，只勾选筛选结果；适合先处理一部分、再继续处理剩下的歌曲。

## v1.6 新增（B 站封面）

- **单曲 B 站封面**：点“查看歌曲” → 某首歌右侧编辑 → “从 B 站获取”，粘贴视频链接、分享文字、BV 号、av 号或 b23.tv 短链接。保存后，这首歌写入时会优先使用这张封面，覆盖歌手组封面。
- **整组 B 站封面**：歌手卡片的“B站封面”会把一张视频封面应用到整组歌曲。
- 封面会自动居中裁成正方形 JPEG；只读取 B 站公开视频信息和封面，不登录、不下载视频。
- 视频被删除、区域限制或 B 站接口拒绝时，对话框里会显示失败原因。

## v1.4 重要修复（B 站音频）

很多 B 站下载的音频原来是 `.m4s`，改成 `.mp3` 或 `.m4a` 后能播放，但内容是分片 MP4。

v1.4 修复了这类文件在安卓上的重封装失败：

- 之前 mp4parser 从“系统类加载器”读取 `isoparser2-default.properties`，安卓上读不到，最终报 `NullPointerException: inStream parameter is null`。
- v1.4 改为从 App 自己的类加载器预加载该配置，再执行重封装。
- 已用模拟 Android 类加载器的测试复现旧错误，并确认 v1.4 可以正常完成重封装。
- 修复后的文件会写标签并改名为 `.m4a`，不再保留 `.mp3` 后缀。

v1.3 已经修复的“M4A 内容保留 `.mp3` 后缀”问题仍然保留：写入失败不覆盖原文件，写入前先写临时文件，音轨校验通过后才替换。

## 为什么有时只有专辑变化

如果文件本来就有正确的 `ARTIST`、`ALBUM_ARTIST` 和封面，App 再写入相同内容时不会产生可见变化；这时最容易被注意到的变化通常是专辑。仅凭写入后的结果无法判断原专辑是否为空，所以不要把它直接当成写歌手或封面失败。可以在单曲编辑里修改歌手、在歌手卡片里重新选封面后再测试。

## 使用

1. 选择音乐文件夹，App 会递归扫描支持的音频。
2. 按歌手自动分组。文件名按 `歌手名 - 歌曲名` 识别，也支持 `歌手名-歌曲名`、`[mqms2]` 后缀和重复扩展名。
3. 每个歌手组默认专辑是“投稿”，可以单独改；文件夹里有 `cover.jpg`、`folder.jpg`、`封面.jpg` 等会自动使用。
4. 点“查看歌曲”可以逐首勾选、修改歌名、歌手和专辑。
5. 识别不到歌手时，在单曲编辑里手动填写。勾选“记住这个文件夹”后，这个文件夹里以后新增的、识别不到歌手的歌曲会自动归到这个歌手。
6. 也可以点“文件夹歌手记忆”集中管理。适合一个文件夹只有一位歌手的情况；混放多位歌手的文件夹不要设置。
7. 每个歌手卡片可以设置本组专辑；也可以在某首歌的单曲编辑里单独填写专辑。
8. 确认后点底部“开始写入”。完成后可从“写入记录”查看失败、跳过、成功三个分段。
9. 如果文件名还需要统一，在歌手卡片点“按歌手改名”。只处理已勾选的歌曲，建议先确认歌手名正确，再执行。
10. 想继续处理没写完的歌：点“查看歌曲”，筛选“未写入”，再点“仅选当前”。
11. 需要按专辑分批整理时：点“批量选择与专辑” → “按专辑筛选”，选择专辑后点“全选当前”或逐首勾选，填写新专辑名并写入。
12. 需要 B 站视频封面时：单曲用编辑里的“从 B 站获取”，整组用歌手卡片的“B站封面”。
13. 需要直接新增 B 站音频时：点右上角下载图标，粘贴链接/BV 号/av 号，填写歌手和歌曲名（歌曲名可留空），确认专辑后点“下载并写入”。视频封面会自动写入，完成后自动扫描到列表里。

## 写入选项

- **同时写入歌名**：从文件名提取歌名并写入标签。
- **同时写入专辑**：把歌手卡片或单曲里设置的专辑写入标签；默认是“投稿”。
- **跳过已处理**：歌手、专辑、歌名、封面都已存在时跳过，适合重复运行。

单曲封面优先于歌手组封面：同一组里可以只有部分 B 站歌曲使用各自的视频封面，其余歌曲继续使用组封面。

写入歌手时会同时写 `ARTIST` 和 `ALBUM_ARTIST`。这样电脑上显示在“参与创作的艺术家”里的名字，手机上也会作为歌手显示。

## 已写入文件的恢复

如果文件被旧版本处理过，先停止继续使用旧版本，并优先从备份恢复整个文件夹。

- 文件开头是 `ftyp`（十六进制 `66 74 79 70`）的，内容通常是 MP4/M4A，只是后缀错了。先复制一份，把后缀改成 `.m4a` 再测试播放。
- 文件开头是 `ID3` 或 `FF FB` / `FF F3` / `FF F2` 的，通常是 MP3，不要改后缀。
- 如果改后缀后播放器仍然卡退，直接恢复备份，不要在原文件上继续反复写标签。
- 不确定时，先用 3～5 个副本测试，确认播放、歌手、封面都正常，再处理整批。

新版重新扫描这些旧输出时，也会把识别出的伪装 `.mp3` 生成为 `.m4a`。但任何自动修复都不能替代备份。

## 支持格式

`mp3`、`m4a`、`m4b`、`flac`、`ogg`、`oga`、`opus`、`wav`、`aiff`、`aif`

`.wav` 会写入 ID3 标签块；写入前后都会做音轨校验，失败时不会替换原文件。

有些下载文件扩展名是 `.mp3`，实际内容却是分片 MP4，尤其是 B 站 `.m4s` 改名文件。App 会自动识别、重封装成普通 M4A，并把最终文件名改成 `.m4a`。

## 注意事项

- 第一次使用先拿 3～5 首歌的副本测试，确认手机上的音乐 App 能正确显示歌手、专辑和封面，再批量处理。
- 建议先备份原始歌曲。写入会直接修改原文件；v1.4 虽然有临时文件和失败保护，但这不是备份。
- 取消批量写入不会回滚已经写好的歌曲。
- 文件夹记忆只补“识别不到歌手”的歌曲，不会覆盖文件名或标签里已有的歌手。
- 混放多位歌手的公共文件夹不要设置文件夹记忆，否则可能归错；这种情况请逐首填写。
- 写完如果音乐 App 没立刻显示新封面，重新扫描媒体库或重启音乐 App。
- 极少数播放器只读 `ARTIST` 或只读 `ALBUM_ARTIST`，本 App 会两个都写，避免换播放器后歌手消失。
- B 站封面和音频下载功能需要联网；封面来自视频信息接口，若视频已删除或接口限制会获取失败，不影响已有本地封面。
- 扫描时显示的是文件内嵌专辑；手动改过专辑的歌曲/歌手组优先使用手动值。重新扫描后如果看到“歌曲”“O&Z”等旧专辑名，说明文件本来就有这些标签，不是 App 新写入的。
- 如果仍然失败，请保留失败记录里的完整异常类、方法、行号和原因链。

## 开发信息

- Kotlin + Jetpack Compose
- 标签引擎：jaudiotagger 3.0.1

## 从源码构建

需要 JDK 17、Android SDK 36 和 Android Studio。

```bash
./gradlew assembleDebug
```

Windows：

```powershell
.\gradlew.bat assembleDebug
```

构建产物在 `app/build/outputs/apk/debug/app-debug.apk`。
